# Configuring-Azure-Resource-Virtual-Machine-Deployment
Hands-on Microsoft Azure project covering how to create an account, resource groups, virtual machines, and virtual networking deployment. 

## Environments and Technologies Used
* Microsoft Azure
* Azure Portal
* Azure Resource Groups
* Azure Virtual Machines
* Azure Storage
* Azure Virtual Network
* Azure Networking
* Remote Desktop Protocol (RDP)

## Operating Systems Used
* Windows 11
* Windows Server

 ## High-Level Deployment and Configuration Steps
1. Create a Microsoft Azure account.
2. Sign into the Azure Portal.
3. Create a Resource Group to organize Azure resources.
4. Create an Azure Virtual Network and subnet.
5. Deploy a Virtual Machine within the Resource Group.
6. Connect to the Virtual Machine using Remote Desktop Protocol (RDP).
7. Verify that the deployed resources are working correctly.
8. Manage, stop, or delete resources when they are no longer needed.
